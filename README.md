# Viaje a España — 旅のしおり

スペイン家族旅行 2026（10/14〜10/21）の静的な旅のしおりサイト。

- 日程タイムライン（フライト・鉄道は搭乗券風カード）
- 日ごとの地図と移動ルート（Leaflet + OpenStreetMap）
- 周辺情報、空港ガイド、お土産ガイド、持ち物チェック
- スマホ対応・オフライン対応（ホーム画面に追加可）

## 編集
内容はすべて `js/data.js` にあります。予定を変えるときはこのファイルだけ直せばOK。

## ローカルで見る
```
python3 -m http.server 8765
```
→ http://localhost:8765

## 注意
公開リポジトリのため、氏名・予約番号・eチケット番号・PNRは載せないこと。
